#  Conexión del BITalino y adquisición de señales EMG

## 📌 Descripción

En este laboratorio se utilizó el sistema **BITalino** para adquirir señales electromiográficas (EMG) provenientes de la actividad muscular. 


---

El primer paso consistió en establecer la comunicación entre el dispositivo **BITalino y la laptop mediante Bluetooth**.

Esta conexión permitió transmitir de manera inalámbrica las señales adquiridas por el BITalino hacia la computadora para su posterior visualización y análisis.

### Procedimiento

1. 🔋 Se encendió el dispositivo BITalino.
2. 📶 Se activó el Bluetooth de la laptop.
3. 💻 Se realizó el emparejamiento entre la laptop y el BITalino.
4. 🔗 Una vez establecida la conexión, se verificó la comunicación entre ambos dispositivos.
5. 📊 Se utilizó el software correspondiente para visualizar y registrar las señales adquiridas.

De esta manera, el BITalino funcionó como el sistema encargado de adquirir las señales provenientes del sensor EMG y transmitirlas inalámbricamente hacia la laptop.

---

#  Conexión del sensor EMG

Después de establecer la conexión entre el **BITalino y la laptop**, se procedió a realizar la conexión del sistema **EMG**.

La electromiografía permitió registrar la actividad eléctrica producida por los músculos durante los procesos de contracción y relajación.

El sensor EMG fue conectado al sistema BITalino para permitir la adquisición de las señales musculares.

---

#  Colocación de los electrodos sobre los músculos

Los electrodos superficiales fueron colocados sobre los músculos seleccionados para registrar su actividad eléctrica.

Para obtener una señal adecuada, se consideraron los siguientes aspectos:

- 💪 Los electrodos fueron colocados sobre el vientre muscular.
- ➡️ Se buscó seguir la orientación de las fibras musculares.
- 🧼 Se procuró que la superficie de la piel estuviera limpia.
- 🦴 Se colocó un electrodo de referencia o punto a tierra sobre una zona ósea, donde existe menor actividad muscular, con el objetivo de reducir interferencias y mejorar la calidad de la señal.
- 📊 Se verificó la calidad de la señal obtenida antes de realizar las mediciones.
